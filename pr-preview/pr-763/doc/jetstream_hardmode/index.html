Hard Mode Rust support for jetstream.

Hard Mode Rust is a style where the library is #![no_std], never allocates, and has all of its resources injected by the caller. Only the (small) binary talks to the OS.

Applying it to every crate in this workspace isn’t possible (QUIC, tokio and friends need an OS), so this crate is the opt-in core: a 9P wire format that works entirely on caller-provided buffers.

  • #![no_std], no alloc, no dependencies.
  • #![forbid(unsafe_code)].
  • No panicking paths: indexing, unwrap and expect are denied by lint, all failures are returned as Error.
  • Decoding is zero-copy; strings, byte blobs and sequences borrow from the input buffer. Arena hands out space from a fixed slice when scratch memory is required.

The encoding is byte-for-byte compatible with jetstream_wireformat (little endian integers, u16 length prefixed strings, u32 length prefixed byte blobs, u16 count prefixed sequences).
