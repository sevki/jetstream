Fixed-size collections using generic const args. Needs a nightly compiler and RUSTFLAGS="-Znext-solver". Fixed-size wire format collections, built on generic const args.

Requires the nightly feature, a nightly compiler and -Znext-solver (e.g. RUSTFLAGS="-Znext-solver"), because it relies on the unstable gca_const_items feature. See https://blog.rust-lang.org/inside-rust/2026/10/02/generic-const-args-and-you/.

Unlike Vec<T>, a [T; N] carries no length prefix on the wire: the length is part of the type, so the encoding is exactly N consecutive elements.
